# Type Master - Improve Your Typing Speed ⌨️

**Live Demo:** https://elite-typer.web.app/

An interactive typing test to check speed, accuracy and improve WPM. Works 100% offline.

### Features
- Real-time WPM & Accuracy tracking (custom JS engine)
- Time sessions (30s, 60s) with state management
- Mistakes highlight with DOM optimization
- Mobile friendly + Keyboard optimized
- Best score saved in LocalStorage

### Tech Stack
- HTML5, CSS3, Vanilla JavaScript (No library)
- Firebase Hosting + GitHub Pages

### What I Learned
- Built typing engine from scratch without using eval() or external libs
- Handled fast keystrokes lag, optimized for high WPM typers
- State handling (idle -> typing -> finished)
